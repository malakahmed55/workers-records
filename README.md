# Workers Records

A small React app for keeping a list of workers: add, edit, delete, view, search and sort. Built as a new frontend based on an earlier workers-table experiment.

- Data is sample data (no real people). Changes are saved in the browser with localStorage. There is no server or database.
- Salary total is shown for the rows currently listed.

## Run

```
npm install
npm run dev
```

Other commands: `npm test` (10 tests with Vitest and Testing Library), `npm run build`.
